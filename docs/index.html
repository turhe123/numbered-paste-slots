Features

Fixed slots, not history.

Everything lives in the menu bar and a few global hotkeys, so your most-used snippets are always one keystroke away.

Paste with a hotkey

Press Control+Option and a digit (1 to 9, then 0) to paste that slot into the frontmost app. Hotkeys use digit-row key codes, so they work across keyboard layouts.

Capture the clipboard instantly

Press Control+Option+Shift and a digit to save whatever you just copied into that slot. Text is preferred, with PNG or TIFF images as the fallback.

Text and images

Each slot holds either text or an image, with an optional label. A per-slot plain-text option strips rich-text formatting from captured text.

Edit and rearrange slots

Edit Slots lets you label and edit every slot, and drag a digit badge onto another row to swap them. Drop image files straight onto an image slot.

Configurable and careful

Choose from nine modifier presets per hotkey, with warnings for identical combinations and known macOS shortcuts. It asks before replacing a filled slot, unless you turn that off.

Menu bar and overview panel

Lives in the menu bar with no Dock icon. A floating overview shows all ten slots in a grid, and a click pastes into the app you were using.

Install

Up and running in a minute.

NumberedPasteSlots is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download NumberedPasteSlots-macOS.zip and unzip it.
  2. Move NumberedPasteSlots.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/NumberedPasteSlots.app
  4. Grant Accessibility access in System Settings → Privacy Security → Accessibility so the app can send Command+V to the frontmost app.

FAQ

Questions, answered.

Is NumberedPasteSlots really free and open source?

Yes. It is released under the MIT license, with no accounts, no servers and no analytics. If it saves you time you can optionally support development through the Support button, but nothing is locked behind it.

What permissions does it need?

Only Accessibility, which is required to send Command+V to the app you are using. Without it, the slot is still copied to the clipboard and a message tells you to press Command+V yourself. It does not request Screen Recording, Microphone, Camera or Contacts.

Where is my data stored?

Locally on your Mac in ~/Library/Application Support/NumberedPasteSlots. Text and slot metadata are kept in a JSON file and images are saved as PNG files. Nothing is sent anywhere.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to run it, or build it yourself from source with Xcode and XcodeGen.
